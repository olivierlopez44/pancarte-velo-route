Pancartes d'entrée de commune

Détecte automatiquement chaque franchissement de limite communale le long d'un tracé GPX, et génère un nouveau fichier avec un waypoint "Entrée [Commune]" à chaque frontière. Aucune installation : tout tourne dans cette page, via l'API OpenStreetMap.

Résultat

Les entrées de commune détectées apparaîtront ici.
Géocodage inverse via l'API publique Nominatim (OpenStreetMap), utilisée dans les limites de son usage raisonnable (~1 requête/s). Pour un tracé de plusieurs dizaines de km, l'analyse peut prendre quelques minutes — laisse l'onglet ouvert. Le fichier exporté conserve l'intégralité du GPX d'origine (horodatages, waypoints existants, extensions) ; seuls les waypoints de pancarte et d'alerte sont ajoutés.
