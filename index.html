Détecte automatiquement chaque franchissement de limite communale le long d'un tracé GPX, et génère un nouveau fichier avec un waypoint "Entrée [Commune]" à chaque frontière. Aucune installation : tout tourne dans cette page, via l'API OpenStreetMap.

Résultat

Les entrées de commune détectées apparaîtront ici.
Données © contributeurs OpenStreetMap. Méthode rapide : limites communales téléchargées en une requête via l'API Overpass, puis calcul local des franchissements (précision ~1 m). Méthode lente : géocodage inverse point par point via Nominatim (~1 requête/s) — utilisée automatiquement si Overpass ne répond pas. Le fichier exporté conserve l'intégralité du GPX d'origine (horodatages, waypoints existants, extensions) ; seuls les waypoints de pancarte et d'alerte sont ajoutés.
